# Competitive Programming Solutions

This repository contains my solutions to competitive programming problems from various online judges and platforms. It serves as a personal archive to track my progress and keep solutions organized for future reference.

## 🚀 Getting Started

### Using the Template

The `template.cpp` file contains a pre-configured C++ template with:
- Common includes (`<bits/stdc++.h>`)
- Useful typedefs and macros
- Debug utilities
- Fast I/O optimizations

To use it:
1. Copy `template.cpp` to your solution file
2. Implement your solution
3. Compile and test
